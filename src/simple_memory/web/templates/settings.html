📌 MCP 配置 (本地模式)

将以下配置添加到你的 Claude Desktop 或其他 MCP 客户端

{
  "mcpServers": {
    "simple-memory": {
      "command": "python",
      "args": ["-m", "simple_memory.mcp_server"],
      "cwd": "{{ config.database.path | replace('./data/lancedb', '') or '.' }}"
    }
  }
}

或者使用 uv 运行:

{
  "mcpServers": {
    "simple-memory": {
      "command": "uv",
      "args": ["run", "simple-memory-mcp"]
    }
  }
}

🌐 远程 MCP 配置 (SSE 模式)

部署到服务器后，通过 URL 远程访问 MCP 服务

1. 启动 SSE 服务器

# 在服务器上运行
simple-memory serve -p 8766

# 或者
python -m simple_memory.mcp_server --transport sse -p 8766

2. 配置 MCP 客户端 (SSE)

{
  "mcpServers": {
    "simple-memory": {
      "transport": "sse",
      "url": "http://YOUR_SERVER_IP:8766/sse"
    }
  }
}

3. 端点说明

  • SSE 端点: http://YOUR_SERVER_IP:8766/sse
  • 健康检查: http://YOUR_SERVER_IP:8766/health
  • Web 管理: http://YOUR_SERVER_IP:8765

注意：确保服务器防火墙开放 8765 (Web) 和 8766 (MCP SSE) 端口
